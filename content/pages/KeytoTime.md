# 时间钥匙 / Key to Time

![key_to_time.png](assets/images/key_to_time.png)

> **类型：** 神器  
> **来源：** DOCTOR M  
> **相关进度：** 宇宙的拥有者  
> **相关物品：** 去物质枪、怀表、永恒水晶  
> **配置项：** `keytoTimeDamage`、`keytoTimeMultiplier`、`keytoTimeExtra`

---

## 概述

**时间钥匙**是一件**终极神器**，能够操控因果、免疫死亡、改写现实。装备后，你将获得近乎不朽的能力。

> ⚠️ **警告：** 时间钥匙是 DOCTOR M 中最强的道具。它提供飞行、复活、伤害免疫、自动回血等一系列能力，还有改变服务器规则的力量，几乎把玩家变成不可击败的存在。

> 💡 **备注：** 时间钥匙尚未完成，部分内容仍待补充。

---

## 装备效果（被动）

**持有时间钥匙**后，以下效果**持续生效**：

| 效果 | 说明 |
|---|---|
| **飞行** | 立即获得飞行能力（创造模式之外也能飞）。 |
| **伤害强制扣血** | 你的所有伤害都将按比例强制扣除对方血量。 |
| **自动回血** | 每秒恢复 **10% 最大生命值**。 |
| **饥饿 / 饱和度回满** | 持续维持满饱食度和满饱和度。 |
| **自动灭火** | 身上着火时立即熄灭。 |
| **氧气供应** | 在无氧环境（太空 / 水下）自动获得**氧合器**效果。 |
| **伤害减免** | 一切伤害最多只能扣 **15% 最大生命值**（见下方详述）。 |
| **血条转移** | 你现有的最大生命值已经成为最大的骗局，它实际上是无限的。 |
| **复活** | 死亡时自动满血复活（见下方详述）。 |

> 装备后如果进入创造 / 旁观模式，再切回生存 / 冒险，也会**自动重新获得飞行**。

**生效位置：** 只要放在**背包任意位置**或**饰品栏**，全部被动效果都会生效。其中**飞行**和**伤害强制扣血**必须装备到**饰品栏**才能生效。

## 伤害处理

时间钥匙对伤害有一套严格的处理流程。

### 伤害类型免疫

以下伤害**完全无效**：

| 伤害类型 | 说明 |
|---|---|
| 火焰、岩浆、高温 | 所有火源。 |
| 药水、魔法伤害 | 直接与间接魔法。 |
| 凋零、溺水、饥饿 | 生理性伤害。 |
| 摔落、仙人掌、甜浆果丛 | 环境伤害。 |
| 冻结、窒息、闪电 | 自然伤害。 |
| 音波、虚空、挤压 | 特殊伤害。 |
| 各类非原版伤害 | 所有非原版伤害全部作废。 |

### 弹射物拦截

任何**非你发射**的弹射物（箭矢、火球等）接触到你会**立即被销毁**，并播放“箭矢命中”音效 + 烟雾粒子。

### 伤害上限

**所有其他伤害**都会被限制为最多扣 **15% 最大生命值**。也就是说，无论敌人打出多高的伤害，你最多掉 3 颗心（以 10 颗心满血计算）。

### 死亡拦截

如果某次伤害会导致你**直接死亡**，时间钥匙会：

1. **立即满血**（阻止死亡）。
2. **触发 2 分钟的保护状态**（见下方）。

---

## 复活机制

当时间钥匙持有者**真正死亡**时（例如被某种绕过限制的机制击杀），会自动触发**复活**：

| 效果 | 说明 |
|---|---|
| **满血复活** | 立即恢复到最大生命值。 |
| **清除所有状态效果** | 无论正面还是负面，全部清空。 |
| **获得抗性提升 II** | 持续 2 秒。 |
| **清场** | 周围 **35 格**内的所有敌对生物被直接击杀。 |
| **音效** | 播放钟声。 |
| **粒子** | 末地烛 + 灵魂火粒子。 |
| **动作栏消息** | 时间钥匙的所有者，你的权力不止于此，你不会被死亡这点小事困扰，六重神依然在注视着你。 |

### 复活后的保护期

复活后 **2 分钟**内，你会获得额外的持续保护：

- 血量持续保持满值。
- 周围 **3 格**内的一切生物会被**持续抹除**（类似去物质枪的效果，伴随末影人传送音效和灵魂粒子）。

> 💡 这个保护期意味着复活后的一段时间内，近战范围内的敌人会被自动清理。

### 冷却

时间钥匙的复活**无视冷却**——这是 2.1 版本加强后的结果。复活优先级被拉到最大。

## 三种可切换模式

时间钥匙支持三种特殊模式。通过**快捷键**（默认为功能键 A / B，可在游戏设置里查看和修改）打开 UI 来切换。

**切换模式时**，动作栏会显示对应的“已开启 / 已关闭”提示。

### 1. God Mode（伤害完全免疫）

| 属性 | 说明 |
|---|---|
| **状态** | 开启 / 关闭。 |
| **效果** | 免疫一切伤害；血量持续保持满值；清除燃烧、凋零、瞬间伤害；补满空气和饱食度；死亡时自动复活。 |
| **代价** | 无。 |

> **开启后你基本无法被杀死。**

动作栏提示：

```text
§a伤害完全免疫已开启
§c伤害完全免疫已关闭
```

### 2. Neutral Mode（生物强制中立）

| 属性 | 说明 |
|---|---|
| **状态** | 开启 / 关闭。 |
| **效果** | 让生物不再主动攻击你。 |

> 目前已知除了坚守者都能强制中立。

动作栏提示：

```text
§a生物强制中立模式已开启
§c生物强制中立模式已关闭
```

### 3. Slash Mode（灵魂收割）

| 属性 | 说明 |
|---|---|
| **状态** | 开启 / 关闭。 |
| **效果** | 攻击任何实体时，触发一次 **5 格范围的斩击效果**。 |

> 与特莉波卡镰刀的灵魂收割类似，但时间钥匙的版本是**被动触发**——只要攻击实体，就会自动释放斩击。

动作栏提示：

```text
§a灵魂收割已开启
§c灵魂收割已关闭
```

## 主动技能

时间钥匙还提供三项**主动能力**，通过 UI 即时切换。

### 切换游戏模式

按顺序循环切换：

```text
生存 → 创造 → 冒险 → 旁观 → 生存 → ...
```

### 切换世界难度

循环切换服务器难度：

```text
和平 → 简单 → 普通 → 困难 → 和平 → ...
```

> 这是**服务端级别**的切换，会影响所有玩家。

### 传送

时间钥匙提供**传送**功能，具体效果见游戏内 UI。

## 自定义称号

时间钥匙支持给持有者设置**自定义称号**。称号会显示在聊天栏里，格式类似：

```text
[称号] 你说的话
```

- 设置方式通过界面完成。
- 称号储存在时间钥匙的 NBT 里，可以被读取和清除。
- 必须装备到**饰品栏**才能生效。

## 与去物质枪的交互

时间钥匙是**去物质枪的克星**：

| 场景 | 无时间钥匙 | 持有时间钥匙 |
|---|---|---|
| 被去物质枪击中 | 物品栏、末影箱、成就全部清空，玩家被抹除。 | **物品栏和末影箱保留**；玩家被处决但**不被抹除**。 |
| 复活 | 从头开始（近似新号）。 | 保有原本的物品和进度。 |

> 这就是为什么时间钥匙被认为是抵御去物质枪的**唯一护身符**。

| 配置项 | 默认值 | 说明 |

## 冷知识

- 时间钥匙是**饰品**，不是手持物品——它放在饰品栏里就能生效。
- 物品名字有**动态颜色**：紫色 → 白色 → 红色 → 白色循环流动。
- 即使不拿在手上，只要放在**背包任意位置**或**饰品栏**，全部被动效果都会生效。
- 装备时间钥匙后进入创造模式再切回生存，**飞行不会丢失**。
- 时间钥匙的复活**无视冷却**——这是 2.1 版本加强后的结果。
