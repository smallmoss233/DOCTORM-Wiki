# 涡旋操纵器 / Vortex Manipulator

> **类型：** 手持式传送设备  
> **来源：** DOCTOR M
> **获取方式：** 103 型塔迪斯交易  
> **相关进度：** 非比寻常的科技  
> **相关配置：** `vortexManipulatorMaxFuel`、`vortexManipulatorMaxOverheat`、`vortexManipulatorCooldownTicks` 等  
> **相关物品：** 阿特隆能量收集单元、航点物品

---

## 概述

**涡旋操纵器**是一台手持式传送设备，允许玩家跨维度设置自定义目的地——代价不菲。

它配备燃料与过热管理系统、航点支持，以及一个完整的交互式界面。

> ⚠️ **警告：** 输坐标的时候最好保险一些，不然你一定不会想 CosPlay 安德森少校。

> §7廉价的时间旅行设备，速度快到让你的胃来不及跟上。  
> §7没有任何防护结构，填错坐标的话……你会和安德森少校一样，§c卡在天花板里§7。  
> §7（BT，我找到安德森了...他在...天花板里。）

## 界面

手持涡旋操纵器右键即可打开界面。

```text
┌─────────────────────────────────────┐
│          涡旋操纵器                   │
│                                     │
│  [Z]          <  [目标维度]  >       │
│  [Y]          [设为当前位置]          │
│  [X]          [设为上一位置]          │
│                                     │
│  能量：1420/1500                     │
│  热量：23                            │
│                                     │
│       [关闭]        [前往]            │
└─────────────────────────────────────┘
```

### 控件说明

| 元素 | 作用 |
|---|---|
| **Z / Y / X 输入框** | 手动输入目标坐标，与物品 NBT 实时同步。 |
| **< / > 按钮** | 循环切换可前往的维度（跳过 `ait-tardis` 内部维度）。 |
| **设为当前位置** | 把你当前位置和维度保存为目标。 |
| **设为上一位置** | 把当前目标换成**上一个**目标（方便往回跳）。 |
| **前往** | 尝试传送。服务端会校验燃料、热量、冷却和维度锁定。 |

> 💡 **提示：** 坐标输入框从上到下依次是 **Z、Y、X**。

## 燃料与过热

每次传送消耗**燃料（AU）**并产生**过热**。两个资源相互独立。

### 燃料

| 属性 | 说明 |
|---|---|
| **范围** | 整数，**0–1500**。 |
| **低燃料警告** | 低于 **100** 时 Tooltip 变红。 |
| **不足时** | 传送取消。 |

### 过热

| 属性 | 说明 |
|---|---|
| **范围** | 整数，**0–100**。 |
| **积累** | 距离越远，积累越多。 |
| **自然散热** | 放在物品栏中每 **4 秒**下降 **1 点**。 |
| **熔毁** | 达到 **100** 时设备**熔毁**。 |

---

## 传送消耗

每次传送前，服务端会计算消耗。

### 基础公式

| 消耗 | 公式 |
|---|---|
| **燃料** | `ceil(5 + 距离/50 + 距离² / 10,000,000)` |
| **过热** | `ceil(距离/800 + 距离² / 4,000,000)` |

> `距离` = 玩家到目的地的直线距离。

### 燃料加成系数

基础燃料消耗会被**所有满足条件**的系数累乘：

| 条件 | 系数 | 原因 |
|---|---|---|
| **跨维度** | ×1.5 | 跨维度跳跃代价更高。 |
| **极端高度**（Y > 200 或 Y < 16） | ×1.15 | 高空 / 低层大气不稳定。 |
| **移动中**（速度² > 0.01） | ×1.1 | 锁定移动目标更耗能。 |
| **危险落点**（目标下方 5 格内无实心方块） | ×1.2 | 稳定落点需要额外能量。 |

### 硬性限制

- 最终燃料消耗超过 **3,000 AU**（最大燃料的 2 倍）时，**直接拒绝**——距离太远。
- 必须**手握足够燃料**，不允许“跳一半”。

---

## 时间病

远距离传送有**时间位移症**的风险。

| 距离 | 概率 | 效果 |
|---|---|---|
| **> 500 格** | **10%** | 凋零 I、反胃 I、虚弱 V、缓慢 IV、饥饿 II。 |
| **> 5,000 格** | **15%** | 同上，概率更高。 |

**持续时间**：`距离 / 50` 秒。

- 例如 1,000 格 = 20 秒。
- 5,000 格 = 100 秒。
- 落地**之后**生效。

动作栏提示：

```text
§4警告：时间流撕裂了你的生理结构。无防护跃迁后遗症发作，预计持续 %d 秒。
```

## 熔毁与修复

过热达到 **100** 时，涡旋操纵器**熔毁**：

- 设置 **3 天修复计时**（72,000 个主世界 tick）。
- 对玩家造成 **4 HP** 伤害。
- 附加**中毒**（5 秒）。
- 显示粗体暗红警告：

```text
§4警告：核心熔毁。涡旋操纵器已锁定，强制冷却程序启动。预计恢复时间：3天。
```

### 熔毁期间

| 项目 | 说明 |
|---|---|
| **物品栏条** | 变**暗红**。 |
| **使用尝试** | **6 HP** 伤害、**中毒 II**（10 秒）、**缓慢 II**（10 秒）、**失明**（5 秒）。 |
| **聊天栏提示** | 剩余天数。 |

尝试使用时会显示：

```text
§4错误：核心熔毁。强行操作已造成损伤。
§4设备离线。预计恢复：%s 天。
```

### 自动修复

3 天计时结束后，设备**自动修复**：

- 清除熔毁标记。
- 过热重置为 **0**。
- 显示绿色“冷却完成”消息：

```text
涡旋操纵器冷却结束，可以再次使用。
```

> 💡 没有手动修复道具，只能等。

## 充能

**副手**持**阿特隆能量收集单元**，**主手**持涡旋操纵器，**潜行 + 右键**。

| 情况 | 结果 |
|---|---|
| **正常充能** | 从收集单元把 AU 转移到设备，最多转移到设备剩余容量。 |
| **设备已满** | 操作失败并给出提示。 |
| **收集单元为空** | 操作失败并给出提示。 |

充能成功会显示：

```text
充能：+%s 阿特隆能量 (VM: %s/%s)
```

## 航点

你可以从兼容的航点物品中载入坐标：

1. 把航点物品（如航点磁盘 / 控制盘）放到**副手**。
2. **潜行 + 右键**（主手持涡旋操纵器）。
3. 如果副手物品带有 `pos.{X,Y,Z,dimension}` 的 NBT 路径，目标会被**立即覆盖**。

操作成功会显示航点名字：

```text
已载入航点 "%s"
```

## 限制

涡旋操纵器**无法**传送到：

| 限制 | 结果 |
|---|---|
| `ait-tardis:*` 维度 | 被阻止，这是塔迪斯内部维度。 |
| 被锁定的维度（AIT 配置） | 启用 `lockDimensions` 时被阻止。 |
| 坐标超出 ±30,000,000（X/Z）或 Y < -128 / Y > 512 | 被阻止，避免世界生成崩溃。 |
| 目的地消耗超过 3,000 AU | 被阻止，超出安全操作范围。 |

对应提示：

| 情况 | 提示 |
|---|---|
| 无效维度 | `无效维度！` |
| 维度已锁定 | `维度已锁定！` |
| 能量不足 | `能量不足！需要：%s` |
| 超出安全边界 | `§c目标坐标超出安全边界，系统安全锁定启动。` |
| 距离过远 | `§c预计消耗 %d 能量，超出设备能量极限，系统安全锁定启动。` |
| 冷却中 | `冷却中：%s秒` |

## 配置项

涡旋操纵器的部分数值可在 `config/doctor_m.json` 中调整：

| 键 | 默认值 | 说明 |
|---|---|---|
| `vortexManipulatorMaxFuel` | 1500 | 最大燃料。 |
| `vortexManipulatorMaxOverheat` | 100 | 最大过热。 |
| `vortexManipulatorCooldownTicks` | 1200 | 普通冷却（tick），1200 tick = 60 秒。 |
| `vortexManipulatorBrokenCooldownTicks` | 72000 | 损坏恢复时间（tick），72000 tick = 3 游戏日。 |
| `vortexManipulatorCoolingIntervalTicks` | 80 | 散热间隔（tick）。 |
| `vortexManipulatorCoolingPerInterval` | 1 | 每次散热减少的过热量。 |

## 使用技巧

- **永远先检查落点。** “危险落点”加成会额外增加 20% 消耗。
- **跳之前站定。** 移动状态加 10% 燃料惩罚。
- **规划回程。** 用“设为上一位置”可以瞬间把目标换回出发地。
- **别狂跳远距离。** 过热积累比你想的快，3 天很长。
- **随身带阿特隆能量收集单元。** 跨维度时 1,500 AU 掉得飞快。
- **充能时注意副手。** 副手必须持阿特隆能量收集单元，主手必须持涡旋操纵器，且需要潜行右键。
- **航点可以省去手动输入坐标的麻烦。** 把航点物品放副手，潜行右键即可载入坐标。

## 冷知识

- 涡旋操纵器的界面里，坐标输入框顺序是 **Z、Y、X**，不是常见的 X、Y、Z。
- **熔毁后没有手动修复道具**，只能等 3 个游戏日。
- **熔毁期间强行使用会对自己造成伤害**——6 HP + 中毒 + 缓慢 + 失明。
- **时间病只在落地后生效**，传送过程中不会有任何提示。
- **燃料加成系数是累乘的**——跨维度 + 移动中 + 危险落点 = ×1.5 × 1.1 × 1.2 = ×1.98。
- **过热自然散热只在物品栏中生效**，拿在手上不会散热。
- **“设为上一位置”是回程神器**——跳过去之后立刻再点一次就能锁定回程。
- **维度的循环切换会跳过 `ait-tardis` 内部维度**——你没法用涡旋操纵器直接跳进塔迪斯。
