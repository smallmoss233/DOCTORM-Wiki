# 防御装备 / Defensive Equipment

> **类型：** 防御装备套装  
> **相关物品：** 护盾生成器、力场盾牌  
> **相关配置：** `shieldMaxEnergy`、`forceFieldMaxEnergy` 等  
> **相关生物：** 103 型塔迪斯

---

## 概述

DOCTOR M 提供了两件配套的防御装备，它们协同工作：

| 物品 | 装备位置 | 类型 | 定位 |
|---|---|---|---|
| **护盾生成器** | 饰品（Trinket） | 被动 | 消耗能量吸收来袭伤害。 |
| **力场盾牌** | 主手 / 副手 | 主动 | 展开球形力场，推开实体并焚毁弹射物。 |

> **重要：** 这两件物品共享同一套伤害处理流程。当你受到伤害时，游戏会按**严格的优先级顺序**检查它们。

## 护盾生成器 / Shield Generator

![shield_core.png](assets/images/shield_core.png)

一件被动饰品，放在饰品槽里默默替你挡拳。

### 能量系统

| 属性 | 默认值 | 备注 |
|---|---|---|
| **能量上限** | 可配置，**1000** 点 | 每件物品独立存储于 NBT（`Energy`）。 |
| **充能** | 可配置，每 tick **1** 点 | 装备在饰品槽**或**放在物品栏中都会充能。 |
| **消耗** | 可配置，每点伤害 **5** 点 | 与来袭伤害线性相关。 |

### 行为

- 消耗能量抵御伤害。
- 放在物品栏或饰品槽中都会自动充能。
- 当你正在使用力场盾牌或用原版盾牌格挡时，**不会**保护你。

### 配置项

| 键 | 默认值 | 说明 |
|---|---|---|
| `shieldMaxEnergy` | 1000 | 最大能量存储。 |
| `shieldRechargePerTick` | 1 | 每 tick 被动充能。 |
| `shieldCostPerDamage` | 5 | 吸收每点伤害消耗的能量。 |

## 力场盾牌 / Force Field Shield

![force_field_shield.png](assets/images/force_field_shield.png)

一件主动手持装置，举着时会生成力场抵御怪物 / 弹射物靠近。

### 能量系统

| 属性 | 默认值 | 备注 |
|---|---|---|
| **能量上限** | 可配置，**1500** 点 | 每件物品独立存储于 NBT（`Energy`）。 |
| **充能** | 可配置，每 tick **1** 点 | 仅在**未使用**且**未冷却**时充能。 |
| **消耗** | 可配置，每 tick **2** 点 | 力场激活期间持续消耗。 |

**充能细节：**

- 被动充能每 **4 tick** 生效一次（即每秒恢复 **4** 点）。
- 仅在**未使用**且**未冷却**时充能。
- 若充能时处于**过热**状态且能量填满，会自动解除过热锁定。

### 使用方式

| 操作 | 效果 |
|---|---|
| **按住右键** | 展开力场。 |
| **松开右键** | 释放推开爆发（若不在冷却中）。 |

### 力场激活效果（举盾期间）

| 属性 | 数值 |
|---|---|
| **半径** | 3.5 格（真正的球体）。 |
| **弹射物** | 接触即焚毁（燃烧音效）。 |
| **实体** | 持续被推开。 |
| **推开力度** | `0.25`。 |
| **能量消耗** | 每 tick `2` 点。 |
| **能量上限** | `1500` 点。 |
| **能量耗尽** | 如果能量低于消耗量，力场进入**过热**模式。 |

### 松手爆发（松开右键时）

**仅当力场处于激活状态且未在过热时触发**：

| 属性 | 数值 |
|---|---|
| **半径** | `5` 格。 |
| **效果** | 非玩家实体被水平 + 垂直击飞。 |
| **水平击飞力度** | `1.2`。 |
| **垂直击飞力度** | `0.4`。 |
| **音效** | 铁傀儡攻击的闷响。 |
| **冷却** | `40` tick（`2` 秒）之后才能再次举盾。 |

### 环境伤害减免

力场盾牌对**环境伤害**有额外减免：

| 属性 | 数值 |
|---|---|
| **环境伤害系数** | `0.1`（保留 10%）。 |
| **完全格挡非环境伤害** | 开启（默认）。 |

### 配置项

| 键 | 默认值 | 说明 |
|---|---|---|
| `forceFieldMaxEnergy` | 1500 | 最大能量存储。 |
| `forceFieldDrainPerTick` | 2 | 力场激活期间每 tick 消耗的能量。 |
| `forceFieldRechargePerTick` | 1 | 每 tick 被动充能（每 4 tick 生效一次）。 |
| `forceFieldCooldownTicks` | 40 | 释放爆发后的冷却时间。 |
| `forceFieldPushStrength` | 0.25 | 力场内实体的持续推力。 |
| `forceFieldReleaseRadius` | 5.0 | 释放爆发的半径。 |
| `forceFieldReleaseStrength` | 1.2 | 爆发的水平击退力度。 |
| `forceFieldReleaseUpward` | 0.4 | 爆发的垂直击退力度。 |
| `forceFieldEnvironmentalDamageMultiplier` | 0.1 | 环境伤害保留比例。 |
| `forceFieldBlockAllNonEnvironmental` | true | 是否完全格挡非环境伤害。 |

## 两件装备的协同

两件装备共享同一套伤害处理流程。当你受到伤害时，游戏会按**严格的优先级顺序**检查它们。

| 优先级 | 装备 | 行为 |
|---|---|---|
| 1 | 原版盾牌 | 若正在格挡，优先由原版盾牌处理。 |
| 2 | 力场盾牌 | 若力场激活，由力场处理（焚毁弹射物、推开实体、减免环境伤害）。 |
| 3 | 护盾生成器 | 若前两者未生效，由护盾生成器消耗能量吸收伤害。 |

> 💡 护盾生成器在**你正在使用力场盾牌**或**用原版盾牌格挡**时不会保护你。这是设计上的优先级，避免双重防御。

## 战斗技巧

- **分层防御。** 先举力场盾牌焚毁弹射物，把怪物挡在远处。如果有东西穿透进来而你放下了力场，护盾生成器会接住那一击。
- **注意能量。** 力场盾牌耗能极快。能量耗尽后你会进入强制过热状态，充能完毕前毫无保护。
- **别双重防御。** 同时举着原版盾牌和力场盾牌是多余的——原版盾牌优先，你的能量白白闲置。
- **利用充能间隙。** 两件物品都能在物品栏里充能。战斗间隙可以把力场盾牌换下来，让它回满。
- **护盾生成器很安静。** 除非大战后看一眼能量条，否则你可能不会注意到它救了你。
- **环境伤害也吃减免。** 力场盾牌对火焰、窒息、虚空、凋灵、药水等环境伤害保留 10%，在高危环境中举盾是划算的。
